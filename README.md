Ohm’s Law and Power Calculator

What it does

Ohm’s Law and Power Calculator is a Python program designed to calculate voltage, current, resistance and electrical power using Ohm’s Law.

The program allows users to select the quantity they want to calculate, enter the required electrical values and receive the result with the correct unit.

It also includes a calculation history feature that allows users to view their previous calculations during the program session.

How to run it

1. Install Python 3 on your computer or Android device.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file using the following command:

python ohms_law.py

You can also run the program using a Python application such as Pydroid 3 on Android.

My own twist

I added a Calculation History feature to make the program more useful.

This feature stores successful calculations during the program session and allows users to view their previous results without performing the calculations again.

This makes it easier to keep track of different electrical calculations.
